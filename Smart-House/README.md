# Smart House Viewer

An interactive 3D digital twin of a Smart House, built with [A-Frame](https://aframe.io/) — walk through the space freely in your browser, no headset required.

## About the project

This project was developed as part of the **Erasmus+ Blended Intensive Programme** hosted by [Klaipeda State University of Applied Sciences](https://www.kvk.lt/en) (KVK), Lithuania, during the academic year 2022/2023.

The course, titled *Smart House Virtualization* (3 ECTS), combined a physical week in Klaipeda (14–18 Nov 2022) with a follow-up virtual programme (21–25 Nov 2022). The result is a navigable 3D model of a smart house rendered entirely in the browser using WebXR — no plugins or installation needed.

**Grade received: 10 / 10 — Excellent**

## How to navigate

> **The house is behind you when you first load the page — turn around!**

| Action | Desktop | Mobile |
|--------|---------|--------|
| Move | `W A S D` or Arrow keys | On-screen joystick |
| Look around | Click + drag mouse | Touch drag |

## Built with

- [A-Frame](https://aframe.io/) — WebXR framework
- [aframe-mobile-controls](https://github.com/Ctrl-Alt-Zen/aframe-mobile-controls) — on-screen joystick for mobile
